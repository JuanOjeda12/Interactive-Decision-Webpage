Understand the calculations and ties

Maximax: maximum in each row; the highest wins. Maximin: minimum in each row; the highest wins. Minimax Regret: maximum regret in each row; the lowest wins. EMV / Bayes: sum of payoff × probability; the highest wins.

This model maximizes payoffs; negative values represent losses. Results display two decimal places, while calculations retain full precision. Values within an absolute tolerance of 10⁻⁹ of the best value or cutoff are treated as ties. Probabilities must total 100% (equivalent tolerance: 10⁻⁹).

HTMLindex.html · complete page

Your first decision, step by step

1. Choose a starting point. Load an example or create your own scenario. Switching examples replaces the current data; export first if you want to keep it.

2. Define your matrix. Each row is an alternative and each column a possible state. Enter payoffs, using negative values for losses.

3. Assign probabilities. Use percentages that total 100%. “Balance probabilities” scales the current values proportionally; if all are zero, it distributes them equally.

4. Compare the criteria. They may recommend different alternatives: each reflects a different attitude toward uncertainty.

5. Filter in stages. Choose a criterion and how many alternatives to keep. Ties may cause more alternatives to survive than the number requested.

6. Save your work. The page attempts to save your work in this browser. Export a JSON file for a portable backup. “Print” lets you save the report as a PDF.
